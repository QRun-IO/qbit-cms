# QBit CMS: design

The approved design is the qbit-cms spec in QRun-IO/qqq: [`docs/specs/2026-10-12-qbit-cms-design.md`](https://github.com/QRun-IO/qqq/blob/docs/cms-qbit-design/docs/specs/2026-10-12-qbit-cms-design.md) ([QRun-IO/qqq#1083](https://github.com/QRun-IO/qqq/pull/1083), tracking issue [#1094](https://github.com/QRun-IO/qqq/issues/1094)). The owner accepted every recommendation on 2026-10-12 (decisions D1 to D17).

This repository implements it. The CMS is being extracted from the kof22 website (KofTwentyTwo/Website-Backend), which runs it in production; the in-repo refactors that make it extractable are phase 0 of the spec.
